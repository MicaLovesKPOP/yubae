# 유배지어 / Yubae

넷플릭스 예능 《데블스 플랜: 데드 어게인》의 유배지 문자를 배우고, 입력하고, 나누기 위한 비공식 프로젝트입니다. 프로그램 제작진이나 스텔라장의 공식 프로젝트가 아닙니다.

## 현재 상태 (2026-11-25)

현재 93개의 글자는 사용자가 제공한 손글씨 표를 바탕으로 재구성했습니다. 공식 문자 전체를 확인한 것은 아니며, 글자 모양과 뜻은 원전 대조가 필요합니다. 한국어와 영어를 동등하게 지원합니다.

- Windows, macOS, Linux, Android, iPhone 및 iPad에서 사용할 수 있는 Keyman 패키지
- 문자 중심 화면 및 뜻을 표시하는 학습 화면, 각각 한글·영어 메뉴 지원
- 영어 142개, 한글 233개, 두벌식 키 입력 233개 단축어
- 문법 화면에서 명사·동사·형용사·부사·색 표지를 적용하되, 확인된 형태만 전환
- 이전 Android 버전에서 실제 입력 및 표시 확인. 0.4.0은 빌드와 자동 검사를 통과했으나 실제 기기 확인 필요

## 설치 및 입력

Releases에서 .kmp 파일을 내려받아 Keyman에 설치합니다. 휴대전화에서는 한글 / EN으로 메뉴 언어를 바꾸고, 뜻 / ABC와 문자 / Glyphs 버튼으로 학습 화면을 전환할 수 있습니다. 해당 글자를 길게 누르면 관련 형태가 나옵니다.

물의 글자를 입력하려면 영문 기본 자판에서 /k/anf;를 입력할 수 있습니다. 기존 문맥에 한글이 입력되어 있다면 /물; 규칙도 사용할 수 있습니다. 일반적인 한글 입력기로 검색하고 싶다면 웹 편집기를 권장합니다. 한국어 후보 검색·두벌식 조합 입력의 편의성은 앞으로 개선할 핵심 과제입니다.

유배지어의 정식 유니코드 번호가 없으므로 사적 사용 영역(PUA)을 사용합니다. Keyman 자체 편집기나 지정 글꼴이 있는 앱에서는 표시되지만, 카카오톡 등 일반 앱에서는 네모로 보일 수 있습니다. 이미지 공유와 호환 가능한 텍스트 형식을 함께 제공합니다.

## 연구 및 기여 방향

방송 원전, 방송 후 확인된 용례, 팬 창작을 구분합니다. 새 글자의 출처, 시점, 뜻, 품사, 이견을 기록합니다. 확인되지 않은 형태를 공식 문자라고 소개하지 않습니다. 한국어 사용자의 검토를 적극 환영할 계획이며, 공개 알파를 배포하며 출처와 권리 관계를 계속 검토합니다.

## 웹 편집기 Yubae Studio

[유배지어 편집기 열기](https://micaloveskpop.github.io/yubae/) — 별도 계정이나 글꼴 설치 없이 잠정 문자를 입력하고 읽을 수 있습니다. 한국어·영어 및 한글 초성 검색, 형태 변경, 즐겨찾기, 최근 사용, 기기 내 임시 저장, 이미지 및 메시지 링크 공유를 지원합니다. 지원 브라우저에서 홈 화면 추가 또는 설치를 사용할 수 있으며 최초 로딩 후 오프라인에서도 작동합니다. 링크를 받은 사람은 내용을 읽을 수 있습니다. 현재 알파 버전이며 공식 문자표 대조와 실제 기기 설치 검증은 아직 진행 중입니다.

### 어근 중심 입력 (Studio 0.5.0-alpha.2)
모든 문자는 어근부터 선택합니다. 표지 없음·명사·동사·형용사·부사·색 버튼의 위치가 고정되며, 현재 자료에 기록된 형태만 활성화됩니다. 뜻이 확인되지 않은 어근 자체를 단독 문자로 입력하지 않습니다. 기존 93개 문자의 부호와 호환성은 유지합니다. 현재 83개 어근 그룹은 잠정 분류이며 원전 검토에 따라 달라질 수 있습니다. 모바일 Keyman 입력기의 어근 중심 화면은 다음 구현 대상입니다.

### 어근 입력 업데이트 (Studio 0.5.0-alpha.3, Keyman 0.5.0)
모든 83개 어근을 한 번에 입력할 수 있습니다. 기존 93개 문자는 그대로 유지하며 뜻이 확인되지 않은 어근 67개를 추가했습니다. 어근 입력 후 필요한 표지만 선택하세요. /r/물; 또는 /r/water;로 어근을 입력하고, 하이픈(명사), 마침표(동사), 작은따옴표(형용사), 백틱(부사), 콜론(색)으로 확인된 형태를 만들 수 있습니다. 해당 형태가 없으면 문장부호가 그대로 입력됩니다. 기존 /water; 및 한글 단축키는 유지됩니다. Studio에서는 Escape로 조합을 종료할 수 있습니다. Keyman 터치 키보드는 OK/확정 버튼을 사용합니다. 실제 기기 검증과 원전 확인은 아직 필요합니다.

### 빠른 어근 입력 (Studio alpha.4 / Keyman 0.5.1)
편집기에서 F2 또는 어근 찾기를 누른 후 한국어·영어·초성, ;wa 같은 코드, k/anf 같은 두벌식 키를 검색하세요. 방향키로 후보를 이동하고 Enter로 선택합니다. Esc는 취소입니다. 선택 후 필요할 때 표지 키를 누르세요. ;wa;는 물의 어근을, ;wa;-는 명사형을 입력합니다. 83개 짧은 코드는 선택 사항이며 기존 1,218개 단축키와 160개 문자 부호는 유지됩니다. 실제 기기와 한국어 IME 동작은 추가 확인이 필요합니다.

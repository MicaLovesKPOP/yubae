# 유배지어 / Yubae

넷플릭스 예능 《데블스 플랜: 데드 어게인》의 유배지 문자를 배우고, 입력하고, 나누기 위한 비공식 프로젝트입니다. 프로그램 제작진이나 스텔라장의 공식 프로젝트가 아닙니다.

## 현재 상태 (2026-11-25)

현재 93개의 글자는 사용자가 제공한 손글씨 표를 바탕으로 재구성했습니다. 공식 문자 전체를 확인한 것은 아니며, 글자 모양과 뜻은 원전 대조가 필요합니다. 한국어와 영어를 동등하게 지원합니다.

- Windows, macOS, Linux, Android, iPhone 및 iPad에서 사용할 수 있는 Keyman 패키지
- 문자 중심 화면 및 뜻을 표시하는 학습 화면, 각각 한글·영어 메뉴 지원
- 영어 142개, 한글 233개, 두벌식 키 입력 233개 단축어
- 문법 화면에서 명사·동사·형용사·부사·색 표지를 적용하되, 확인된 형태만 전환
- 이전 Android 버전에서 실제 입력 및 표시 확인. 0.4.0은 빌드와 자동 검사를 통과했으나 실제 기기 확인 필요

## 설치 및 입력

Releases에서 .kmp 파일을 내려받아 Keyman에 설치합니다. 휴대전화에서는 한글 / EN으로 메뉴 언어를 바꾸고, 뜻 / ABC와 문자 / Glyphs 버튼으로 학습 화면을 전환할 수 있습니다. 해당 글자를 길게 누르면 관련 형태가 나옵니다.

물의 글자를 입력하려면 영문 기본 자판에서 /k/anf;를 입력할 수 있습니다. 기존 문맥에 한글이 입력되어 있다면 /물; 규칙도 사용할 수 있습니다. 일반적인 한글 입력기로 검색하고 싶다면 웹 편집기를 권장합니다. 한국어 후보 검색·두벌식 조합 입력의 편의성은 앞으로 개선할 핵심 과제입니다.

유배지어의 정식 유니코드 번호가 없으므로 사적 사용 영역(PUA)을 사용합니다. Keyman 자체 편집기나 지정 글꼴이 있는 앱에서는 표시되지만, 카카오톡 등 일반 앱에서는 네모로 보일 수 있습니다. 이미지 공유와 호환 가능한 텍스트 형식을 함께 제공합니다.

## 연구 및 기여 방향

방송 원전, 방송 후 확인된 용례, 팬 창작을 구분합니다. 새 글자의 출처, 시점, 뜻, 품사, 이견을 기록합니다. 확인되지 않은 형태를 공식 문자라고 소개하지 않습니다. 한국어 사용자의 검토를 적극 환영할 계획이며, 공개 알파를 배포하며 출처와 권리 관계를 계속 검토합니다.
